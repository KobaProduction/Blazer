# Платформенный контракт

| Платформа | Обязательство текущего этапа |
| --- | --- |
| Windows x64, `x86_64-pc-windows-msvc` | Сборка GUI, локальные проверки и CI |
| Linux | Будущая платформа; отдельные build/runtime проверки ещё не настроены |
| Android | Будущая платформа; нужны shell, системный VPN API и lifecycle |
| iOS | Будущая платформа; нужны Apple toolchain, signing и Network Extension |
| Другие устройства | Поддержка определяется отдельным целевым контрактом |

`vpn-domain` и `vpn-application` не привязаны к Windows. Системные API и
особенности VPN-туннеля должны появляться во внешних адаптерах, с target-specific
зависимостями. Не устанавливать Windows target глобальным Cargo default: это
затруднит работу с переносимыми пакетами на других хостах.

Текущий quality gate явно собирает Windows MSVC. Переносимость исходников
не подтверждает работоспособность GUI, VPN API, фоновой службы, ABI или
пакетирования на другой ОС. Инсталлятор и подпись релиза пока не настроены.
